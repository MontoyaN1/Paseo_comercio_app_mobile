# ESQUEMA DE BASE DE DATOS - Paseo del Comercio

## 📊 RESUMEN GENERAL

Base de datos PostgreSQL para la aplicación móvil "Paseo del Comercio", diseñada para gestionar un centro comercial virtual con tiendas, productos, organizaciones y sistema de interacciones.

**Estadísticas:**
- **22 tablas** principales
- **8 tipos personalizados** (enums)
- **40+ relaciones** entre tablas
- **20+ índices** para optimización
- **10+ triggers** para automatización

---

## 📋 TIPOS DE DATOS PERSONALIZADOS (ENUMS)

### 1. `tipo_horario`
```sql
ENUM ('normal', 'especial', 'festivo')
```
**Descripción:** Define el tipo de horario de una tienda.

### 2. `tipo_imagen`
```sql
ENUM ('principal', 'secundaria', 'galeria', 'logo', 'banner')
```
**Descripción:** Clasifica las imágenes según su uso en la aplicación.

### 3. `tipo_organizacion`
```sql
ENUM ('fundacion', 'asociacion', 'cooperativa', 'empresa', 'comunidad', 'otro')
```
**Descripción:** Categoriza las organizaciones registradas.

### 4. `tipo_ubicacion`
```sql
ENUM ('plazoleta', 'pasillo', 'area_comun', 'exterior')
```
**Descripción:** Define el tipo de ubicación física.

### 5. `estado_producto`
```sql
ENUM ('activo', 'inactivo', 'agotado', 'descontinuado')
```
**Descripción:** Estado de disponibilidad de un producto.

### 6. `estado_usuario`
```sql
ENUM ('activo', 'inactivo', 'suspendido', 'eliminado')
```
**Descripción:** Estado de la cuenta de usuario.

### 7. `estado_valoracion`
```sql
ENUM ('publicado', 'pendiente', 'rechazado', 'eliminado')
```
**Descripción:** Estado de moderación de una valoración.

### 8. `tipo_rol`
```sql
ENUM ('admin', 'propietario', 'empleado', 'cliente', 'invitado')
```
**Descripción:** Roles del sistema para usuarios.

### 8. **Consultas Optimizadas para Móvil**
```sql
-- Para lista de tiendas con imágenes principales
SELECT t.*, 
       it.url_imagen as imagen_principal,
       it.url_thumb as imagen_thumb
FROM tienda t
LEFT JOIN imagen_tienda it ON t.id = it.tienda_id 
  AND it.tipo_imagen = 'principal' 
  AND it.activa = true
ORDER BY t.total_visitas DESC
LIMIT 20 OFFSET 0;

-- Para productos con estadísticas
SELECT p.*,
       t.nombre_tienda,
       ip.url_imagen as imagen_principal,
       COUNT(vp.id) as total_valoraciones
FROM producto p
JOIN tienda t ON p.tienda_id = t.id
LEFT JOIN imagen_productos ip ON p.id = ip.id_producto 
  AND ip.tipo_imagen = 'principal' 
  AND ip.activa = true
LEFT JOIN valoracion_producto vp ON p.id = vp.producto_id 
  AND vp.estado_valoracion = 'publicado'
WHERE p.estado_producto = 'activo'
GROUP BY p.id, t.nombre_tienda, ip.url_imagen
ORDER BY p.total_visualizaciones DESC
LIMIT 50 OFFSET 0;
```
