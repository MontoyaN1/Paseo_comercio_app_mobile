## Uso

Los archivos `.mmd` pueden visualizarse en:
- [Mermaid Live Editor](https://mermaid.live)
- VS Code con extensión Mermaid
- GitHub (renders automáticamente en Markdown)
- GitLab (renders automáticamente en Markdown)

- Modelo Entidad-Relación completo

- Jerarquía de organizaciones y plazoletas

### diagrama_favoritos.mmd
- Arquitectura del sistema de favoritos
- Flujo de usuario (agregar/quitar favoritos)
- Carga de favoritos
- Estados del BLoC
- Navegación y UI
